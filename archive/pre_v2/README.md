# Pre-V2 Archive

本目录保存 Adaptive Skill Mining v2 之前的分析与 Skill 资产，供历史复现，
不再作为当前默认流水线。

```text
pre_v2/
├── analysis/
│   ├── run_pipeline.py
│   ├── phase1_audit/
│   ├── pipeline/          # Phase 2–8
│   ├── plan2/
│   └── outputs/           # 旧分析产物
├── SKILL/                 # plan2 pilot skills
└── plans/                 # plan.md / plan_2.md
```

历史命令需从仓库根目录运行，并将旧模块路径视作归档路径。当前实现和命令见
[`analysis/skill_mining_v2/README.md`](../../analysis/skill_mining_v2/README.md)。
