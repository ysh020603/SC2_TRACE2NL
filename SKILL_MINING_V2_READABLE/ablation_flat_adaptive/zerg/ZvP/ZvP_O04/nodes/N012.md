# N012 — Early Game Tech Investment

## Node Type

DEFAULT

## Summary

Early game, opponent unknown with Zealot, own ground macro with light production. Strengthen ground, increase economy and expansion, increase production, continue tech, improve defense.

## When This Applies

### Opponent cues

- Unknown posture, heavy economy, moderate expansion, moderate production, heavy tech. Zealot seen.
- Treat remembered or observed Enemy Intelligence as partial and uncertain.

### Own cues

- Ground macro posture, heavy economy, light production and tech. No combat units yet.
- Use the live observation to check army supply, free supply, resource bank, technology, and current queues.
- These cues are approximate and do not all need to be true.

## Recommended Strategic Direction

Strengthen ground, increase economy and expansion, increase production, continue tech, improve defense.

Opponent's heavy tech investment suggests a tech-based build, so investing in tech and economy is safe. Increasing production prepares for early defense.

## What This Does NOT Mean

This node is not an instruction to reproduce a historical action sequence.

Choose exact macro actions from the current live observation, not merely because a unit or structure appeared in historical evidence.

## Transition Goal

Reach early-midgame with a solid economy and tech foundation.
