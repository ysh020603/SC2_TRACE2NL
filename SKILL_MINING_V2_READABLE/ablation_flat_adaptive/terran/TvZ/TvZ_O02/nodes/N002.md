# N002 — Late Midgame with Unknown Opponent

## Node Type

DEFAULT

## Summary

Late midgame, opponent still unknown, no reliable combat-unit cues. Maintain current development path, but start considering army composition based on map and your own tech choices.

## When This Applies

### Opponent cues

- Enemy Intelligence still shows no reliable combat-unit cues. Production and tech appear light or uncertain.
- Treat remembered or observed Enemy Intelligence as partial and uncertain.

### Own cues

- Your own posture remains unknown-oriented with light production and tech. You have not committed to a specific army composition.
- Use the live observation to check army supply, free supply, resource bank, technology, and current queues.
- These cues are approximate and do not all need to be true.

## Recommended Strategic Direction

Maintain current development path, but start considering army composition based on map and your own tech choices.

Even without opponent info, you need to prepare for potential engagements. A balanced army with tech upgrades is safe.

## What This Does NOT Mean

This node is not an instruction to reproduce a historical action sequence.

Choose exact macro actions from the current live observation, not merely because a unit or structure appeared in historical evidence.

## Transition Goal

Start building a core army while continuing tech and economy development.
