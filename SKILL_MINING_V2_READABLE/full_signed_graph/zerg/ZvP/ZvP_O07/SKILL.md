# ZvP_O07 Economy / Production / Expansion

## Skill Identity

- Skill ID: ZvP_O07

- Opening Family: economy / production / expansion opening

## Opening Strategy

This opening focuses on building a strong economy and production infrastructure while maintaining a flexible ground-oriented posture. It aims to support heavy expansions and tech development, with a moderate early army to defend against potential pressure.

Develop a robust economy and production base while preserving flexibility to adapt to opponent's tech choices, transitioning into a strong midgame army.

This is a strategic template, not a fixed build order. Adapt based on live scouting and opponent's actions.

## Strategic Characteristics

- Economy: heavy
- Production: moderate
- Technology: light_or_uncertain
- Army direction: ground-leaning
