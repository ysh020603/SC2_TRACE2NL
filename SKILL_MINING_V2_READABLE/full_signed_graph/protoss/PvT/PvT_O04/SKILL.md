# PvT_O04 Technology / Defense / Economy

## Skill Identity

- Skill ID: PvT_O04

## Opening Strategy

A Protoss opening that prioritizes heavy technology investment and defensive stability while building a strong economy. The early game is characterized by moderate production and a focus on tech structures, with the army composition leaning ground but retaining flexibility to transition into air if scouting suggests it.

Develop a technology / defense / economy posture while preserving flexibility for live observation-driven adaptation.

This is a strategic template, not a fixed build order.

## Strategic Characteristics

- Economy: moderate
- Production: moderate
- Technology: heavy
- Army direction: ground-leaning
