# N001 — Early Game Development

## Node Type

TRACE

## Summary

At the start of the game, focus on establishing a solid economy and tech foundation while keeping options open. Maintain current development path, prioritizing economy and tech while keeping production moderate.

## When This Applies

### Opponent cues

- No reliable information about the opponent's strategy or composition yet.
- Treat remembered or observed Enemy Intelligence as partial and uncertain.

### Own cues

- Early game with heavy economy and tech investment, moderate production, and light defense. Army composition is unknown.
- Use the live observation to check army supply, free supply, resource bank, technology, and current queues.
- These cues are approximate and do not all need to be true.

## Recommended Strategic Direction

Maintain current development path, prioritizing economy and tech while keeping production moderate.

A balanced macro start allows flexibility to react to opponent's moves without committing to a specific strategy.

## What This Does NOT Mean

This node is not an instruction to reproduce a historical action sequence.

Choose exact macro actions from the current live observation, not merely because a unit or structure appeared in historical evidence.

## Transition Goal

Reach a stable early-midgame position with a solid economy and tech base.
