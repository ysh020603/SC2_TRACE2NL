# N002 — Early-Midgame Consolidation

## Node Type

COMMON

## Summary

Early-midgame phase, still with light or uncertain production and tech, but with more game time elapsed. Maintain current development, but start to lean toward a ground-oriented army if you have scouted no air threat.

## When This Applies

### Opponent cues

- Opponent's strategy is still unclear; maintain map awareness and be prepared for aggression.
- Treat remembered or observed Enemy Intelligence as partial and uncertain.

### Own cues

- Your economy is still developing, but you have more options available. Keep production and tech balanced while scouting for opponent's intentions.
- Use the live observation to check army supply, free supply, resource bank, technology, and current queues.
- These cues are approximate and do not all need to be true.

## Recommended Strategic Direction

Maintain current development, but start to lean toward a ground-oriented army if you have scouted no air threat.

As the game progresses, you need to start committing to a composition. Ground is a safe default in TvT, but be ready to adapt.

## What This Does NOT Mean

This node is not an instruction to reproduce a historical action sequence.

Choose exact macro actions from the current live observation, not merely because a unit or structure appeared in historical evidence.

## Transition Goal

Transition to a more defined army composition by midgame.
