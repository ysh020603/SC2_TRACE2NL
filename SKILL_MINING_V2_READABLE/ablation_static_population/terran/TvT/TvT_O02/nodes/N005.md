# N005 — Early Game Tech Investment

## Node Type

COMMON

## Summary

Early game with moderate production and heavy technology investment. Increase production and strengthen ground army, while continuing tech development.

## When This Applies

### Opponent cues

- Opponent's actions are unknown; maintain awareness.
- Treat remembered or observed Enemy Intelligence as partial and uncertain.

### Own cues

- You are investing heavily in technology, with moderate production. This suggests a tech-heavy build.
- Use the live observation to check army supply, free supply, resource bank, technology, and current queues.
- These cues are approximate and do not all need to be true.

## Recommended Strategic Direction

Increase production and strengthen ground army, while continuing tech development.

Heavy tech investment can give you an advantage later, but you need production to support it. Strengthening ground army provides defense.

## What This Does NOT Mean

This node is not an instruction to reproduce a historical action sequence.

Choose exact macro actions from the current live observation, not merely because a unit or structure appeared in historical evidence.

## Transition Goal

Transition to a strong midgame army with tech advantages.
