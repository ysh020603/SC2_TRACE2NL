# N003 — Midgame Baseline

## Node Type

COMMON

## Summary

Midgame, own posture remains broadly unknown with light or uncertain production and technology. No clear army composition or pressure posture. Maintain current development path with safety checks. This is a critical time to start committing to a strategic direction.

## When This Applies

### Opponent cues

- Opponent information is not available in this projection.
- Treat remembered or observed Enemy Intelligence as partial and uncertain.

### Own cues

- You are in the midgame with an unclear economic and production posture. Technology investment is still light or uncertain. No representative units are confirmed.
- Use the live observation to check army supply, free supply, resource bank, technology, and current queues.
- These cues are approximate and do not all need to be true.

## Recommended Strategic Direction

Maintain current development path with safety checks. This is a critical time to start committing to a strategic direction.

By midgame, you need to have a coherent plan to avoid falling behind. Maintaining flexibility is no longer sufficient.

## What This Does NOT Mean

This node is not an instruction to reproduce a historical action sequence.

Choose exact macro actions from the current live observation, not merely because a unit or structure appeared in historical evidence.

## Transition Goal

Transition into a concrete army composition and tech path, likely ground-oriented with heavy production and tech.
